# Concept interactif PlayStation 5

Maquette statique d’une page d’accueil avec scène 3D manipulable et quatre modèles GLB.

## Prévisualisation locale

Ouvrir `index.html` via un serveur HTTP local (les modules JavaScript et les modèles GLB ne se chargent pas correctement avec `file://`).

## GitHub Pages

Publier le contenu de ce dossier dans un dépôt GitHub, puis activer GitHub Pages sur la branche et le dossier utilisés. Le site charge Three.js et la police depuis des CDN ; une connexion Internet est requise.

Les fichiers GLB pèsent environ 62 Mo au total, dont le modèle DualSense à lui seul environ 42 Mo. Pour une mise en ligne, optimiser les modèles peut améliorer le temps de chargement.
